记录一下这个博客从零到上线的过程，给想搭静态博客的朋友一个参考。

## 技术选型

| 方案 | 优点 | 为什么没选 |
| --- | --- | --- |
| WordPress | 生态成熟 | 太重，需要数据库 |
| Next.js | 灵活强大 | 杀鸡用牛刀 |
| Hugo | 构建飞快 | 主题生态偏少 |
| **Hexo** | 生态成熟、主题自由、中文社区活跃 | ✅ 就是它了 |

## 搭建步骤

```bash
# 安装
npm install hexo hexo-server hexo-renderer-ejs hexo-renderer-marked

# 本地预览
npm run dev

# 生成静态文件
npm run build
```

## 自定义主题

没有使用现成主题，而是手写了一个极简主题：

- **排版**：大字号标题 + 等宽字体点缀，向以太坊官网的排版致敬
- **配色**：近白底色 + 电子紫点缀，支持深色模式
- **页面**：首页 / 归档 / 标签 / 关于，标准的个人博客结构

静态博客的浪漫在于：一堆 HTML 文件，扔到任何服务器上就能跑，十年后打开还是原样。
